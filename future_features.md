# Project Arc — Product Roadmap & Future Features

> **Version:** 1.0.0 (Production Release)  
> **Document Purpose:** Structured feature roadmap categorized into MVP (Completed), v2 (Near-Term), v3 (Medium-Term), and Long-Term Vision.

---

## 🟢 MVP (Completed v1.0.0)
- [x] Single-user local-first architecture (Hive + Cloud Firestore sync).
- [x] Task Manager with priority, sorting, categories, and 3-tier notifications.
- [x] Habit Tracker with 7-day matrix grid, streaks engine, and goal pie chart.
- [x] Money Tracker with historical monthly budgets, categories expansion, monthly summary archiving, and 4 animated analytics.
- [x] Integrated Dashboard with Productivity Score (0-100), Recent Activity Feed (top 10), and FAB Quick Actions.
- [x] Global Search, Notification Center, and Settings with Dark/Light theme switching.

---

## 🟡 Version 2.0 (Near-Term Roadmap)
- [ ] **Recurring Tasks**: Daily, weekly, monthly, or custom interval repeating task creation.
- [ ] **CSV & JSON Export**: Export transaction ledgers and completed task logs to CSV / JSON files.
- [ ] **Android Home Screen Widgets**: Quick task checklist widget and daily habit check-in bubbles widget.
- [ ] **Biometric Lock**: Optional Fingerprint / FaceID security prompt when opening financial tabs.

---

## 🔵 Version 3.0 (Medium-Term Roadmap)
- [ ] **Google Calendar Sync**: 2-way event and task synchronization with Google Calendar.
- [ ] **Pomodoro Timer**: Integrated focus timer linked to task completion.
- [ ] **Backup to Google Drive**: Encrypted database export to personal Google Drive storage.
- [ ] **Wear OS Companion App**: Quick habit check-in and task completion app for Wear OS smartwatches.

---

## 💜 Long-Term Vision
- [ ] **AI Productivity Insights**: On-device LLM analysis providing personalized advice on peak productivity hours, habit completion trends, and spending habits.
- [ ] **OCR Expense Scanner**: Camera scanning of paper receipts using ML Kit OCR to auto-fill transaction forms.
- [ ] **Voice Task & Transaction Entry**: Natural language voice input ("Remind me to buy groceries tomorrow at 5 PM", "Spent $15 on lunch").
